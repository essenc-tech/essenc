QuickBill Customer Display

v1.0.0

Android Companion App for Live Customer Display

QuickBill Customer Display is a lightweight Android app that shows live bill details, item list, quantities, and total on a second screen during checkout. Pair it with QuickBill desktop for a professional dual-display experience in retail stores.

Android Local Network Open Source MIT License
Download APK Android · v1.0.0 GitHub

Features

Everything needed for a clean customer-facing display during billing.

Live Bill Display

Shows the current bill in real time as items are added on the main QuickBill app.

Item List & Qty

Clear list of products, quantities, and prices visible to the customer.

Running Total

Always-visible total amount so customers can follow the bill as it grows.

Local Network Pairing

Connects to QuickBill desktop over the same Wi-Fi / local network.

Tablet & Phone Ready

Works on Android phones and tablets — use any secondary device as display.

Clean Full-Screen UI

Distraction-free, high-contrast layout designed for customers to read easily.

Lightweight & Fast

Small APK size and smooth updates with minimal battery impact.

No Internet Required

Works fully offline on the local network after pairing.

Open Source

Fully open source under the MIT license. Inspect and contribute.

Tech Stack

Built with modern Android tools for reliability and performance.

Kotlin Android SDK Jetpack Material Design WebSocket / Local Network JSON
